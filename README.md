## Getting started

To run a Python file from this repository, first install Python 3, then open a terminal in the project folder and run:

```bash
python3 your_file.py
```

On Windows, you may be able to use `python` instead:

```bash
python your_file.py
```

Replace `your_file.py` with the name of the Python file you want to run.
